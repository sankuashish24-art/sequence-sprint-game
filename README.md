# Sequence Sprint

A clean and creative memory game built with HTML, CSS, and vanilla JavaScript.

## How to play

1. Click **Start the sprint**.
2. Watch the highlighted tiles.
3. Click the tiles in exactly the same order.
4. Every successful round adds one tile.
5. You have three mistakes available.
6. Complete eight rounds to win.

## Features

- Pattern-memory gameplay
- Eight increasing rounds
- Three lives
- Score system
- Best score saved in local storage
- Simple sound effects
- Responsive interface
- No installation required

## Run locally

Open `index.html` in your browser, or use VS Code Live Server.
